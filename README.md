# Análise de vendas com SQL e Python

Projeto de estudo: carrego um conjunto de dados público de e-commerce em um banco SQLite e respondo perguntas de negócio com consultas SQL. Depois uso Python e pandas para analisar os resultados e gerar gráficos.

## Status
Em andamento. Já feito: escolha do dataset e das perguntas de negócio.

## Dados
- Fonte: Brazilian E-Commerce Public Dataset by Olist (Kaggle)
- Conteúdo: pedidos de uma loja online brasileira, em 9 arquivos CSV (pedidos, clientes, itens, produtos, pagamentos, avaliações e outros)
- Os arquivos CSV não estão neste repositório, por causa do tamanho. Podem ser baixados no Kaggle.

## Perguntas de negócio
1. Quantos pedidos foram feitos em cada mês?
2. Quais são os 5 estados com mais clientes?
3. Qual a quantidade de pedidos por status?
4. Quantos clientes compraram mais de uma vez?
5. Quantos pedidos chegaram depois da data prometida?
